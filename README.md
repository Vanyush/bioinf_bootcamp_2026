# MMNV (Modern Mitochondrial Network Visualizer)

Алгоритм для анализа митохондриальных ДНК-последовательностей, построения временной сети гаплогрупп и прогнозирования возраста недатированных образцов.

## Общее описание

Алгоритм предназначен для работы с выравненными митохондриальными последовательностями в формате FASTA. Основные этапы обработки:

### 1. Парсинг и группировка последовательностей

На вход подаётся FASTA-файл, где заголовки последовательностей могут содержать возраст образца (ожидается числовое значение после последнего символа _). Алгоритм:
- Считывает последовательности и извлекает возраст из заголовков
- Объединяет идентичные последовательности в гаплогруппы
- Каждая гаплогруппа получает уникальный идентификатор (HG1, HG2, ...)

### 2. Вычисление генетических дистанций

Попарное сравнение последовательностей гаплогрупп с учётом:
- Игнорирование гэпов (-) и неопределённых нуклеотидов (N)
- Подсчёт только сопоставимых позиций
- Результат - матрица расстояний между всеми гаплогруппами

### 3. Построение сети гаплогрупп

На основе матрицы расстояний строится взвешенный граф, где:
- Узлы - гаплогруппы
- Рёбра соединяют генетически близкие группы
- Используется комбинация квантильного порога и минимальных расстояний по строкам

### 4. Инференция возраста

Для прогнозирования возраста недатированных гаплогрупп используется итеративный алгоритм:

Начальная оценка - взвешенное среднее возрастов датированных соседей с весами, обратно пропорциональными квадрату генетической дистанции.

Итерационное сглаживание в течение 250 итераций:

Новый_возраст рассчитывается как сумма 70% от среднего по соседям в графе и 30% от ближайших датированных.

### 5. Оценка достоверности

Для каждой прогнозной гаплогруппы вычисляется метрика достоверности на основе:
- Ближайшего расстояния до датированной группы
- Локального разброса возрастов в окрестности графа

### 6. Визуализация

Построение временной сети, где:
- Ось X - возраст (лет назад), древние образцы слева
- Ось Y - случайное вертикальное распределение для читаемости
- Цвет узла: синий - датированные образцы, оранжевый - прогнозные
- Размер узла пропорционален количеству образцов в гаплогруппе

## Выходные данные

Алгоритм генерирует:
- CSV-таблицу с предсказанными возрастами, достоверностью и принадлежностью к гаплогруппам для каждой последовательности
- Визуализацию сети в виде графа (PNG для версии командной строки, интерактивная для веб-версии и графической версии для macOS)

## Использование

### Для macOS
Для устройств на macOS выпущена [программа с GUI](https://github.com/Vanyush/bioinf_bootcamp_2026/releases/tag/test-version). Исходный код предоставлен в [mmnv_swift](https://github.com/Vanyush/bioinf_bootcamp_2026/tree/main/mmnv_swift). 
В качестве языка был выбран Swift по нескольким причинам:
1. Это современный кросс-платформенный компилируемый язык, обеспечивающий производительность на уровне C, при этом гарантирующий безопасность кода.
2. Под macOS Swift имеет нативный декларативный фреймворк SwiftUI, который позволяет быстро разрабатывать интуитивно-понятный GUI. Использование фреймворка Qt для C++ или egui для Rust значительно увеличило бы время разработки программы, что не позволило бы вложиться в 3 дня хакатона.
3. Отсутствие фреймворка SwiftUI на Linux и Windows может компенсироваться схожим фреймворком [SwiftCrossUI](https://github.com/moreSwift/swift-cross-ui), который позволяет переработать программу с минимальным изменением в коде.

При использовании приложения необходимо загрузить FASTA-файл с набором выровненных митохондриальных последовательностей. После импорта файла автоматически стоится граф. Результаты можно экспортировать как CSV-таблицу.
