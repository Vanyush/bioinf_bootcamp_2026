# MMNV (Modern Mitochondrial Network Visualizer)

Алгоритм для анализа митохондриальных ДНК-последовательностей, построения временной сети гаплогрупп и прогнозирования возраста недатированных образцов.

## Общее описание

Алгоритм предназначен для работы с выравненными митохондриальными последовательностями в формате FASTA. Основные этапы обработки:

### 1. Парсинг и группировка последовательностей

На вход подаётся FASTA-файл, где заголовки последовательностей могут содержать возраст образца (ожидается числовое значение после последнего символа _). Алгоритм:
- Считывает последовательности и извлекает возраст из заголовков
- Объединяет идентичные последовательности в гаплогруппы
- Каждая гаплогруппа получает уникальный идентификатор (HG1, HG2, ...)

### 2. Вычисление генетических дистанций

Попарное сравнение последовательностей гаплогрупп с учётом:
- Игнорирование гэпов (-) и неопределённых нуклеотидов (N)
- Подсчёт только сопоставимых позиций
- Результат - матрица расстояний между всеми гаплогруппами

### 3. Построение сети гаплогрупп

На основе матрицы расстояний строится взвешенный граф, где:
- Узлы - гаплогруппы
- Рёбра соединяют генетически близкие группы
- Используется комбинация квантильного порога и минимальных расстояний по строкам

### 4. Инференция возраста

Для прогнозирования возраста недатированных гаплогрупп используется итеративный алгоритм:

Начальная оценка - взвешенное среднее возрастов датированных соседей с весами, обратно пропорциональными квадрату генетической дистанции.

Итерационное сглаживание в течение 250 итераций:

Новый_возраст рассчитывается как сумма 70% от среднего по соседям в графе и 30% от ближайших датированных.

### 5. Оценка достоверности

Для каждой прогнозной гаплогруппы вычисляется метрика достоверности на основе:
- Ближайшего расстояния до датированной группы
- Локального разброса возрастов в окрестности графа

### 6. Визуализация

Построение временной сети, где:
- Ось X - возраст (лет назад), древние образцы слева
- Ось Y - случайное вертикальное распределение для читаемости
- Цвет узла: синий - датированные образцы, оранжевый - прогнозные

### Выходные данные

Алгоритм генерирует:
- CSV-таблицу с предсказанными возрастами, достоверностью и принадлежностью к гаплогруппам для каждой последовательности
- Визуализацию сети в виде графа (PNG для версии командной строки, интерактивная для веб-версии и графической версии для MacOS)

## Использование

### Для macOS
Для устройств на macOS выпущена [программа с GUI](https://github.com/Vanyush/bioinf_bootcamp_2026/releases/tag/test-version). Исходный код предоставлен в [mmnv_swift](https://github.com/Vanyush/bioinf_bootcamp_2026/tree/main/mmnv_swift). Для компиляции из исходного кода требуется Swift 6+ и Xcode 26+.

При использовании приложения необходимо загрузить FASTA-файл с набором выровненных митохондриальных последовательностей. После импорта файла автоматически стоится граф. Результаты можно экспортировать как CSV-таблицу.

### Для остальных ОС
Для остальных устройств, оснащенных другими системами доступны консольное приложение и веб-приложение:
#### Запуск консольного приложения:
```bash
git clone https://github.com/Vanyush/bioinf_bootcamp_2026.git
cd bioinf_bootcamp_2026/mmnv_python

python MMNV.py <path_to_input_file>.fasta [<output_file>.csv]
```
Где `<path_to_input_file>.fasta` - это путь у файлу с набором выровненных митохондриальных последовательностей, а `<output_file>.csv` - опциональное название выходного файла. При отсутствии последнего параметра выходные файлы будут названы по названию входного файла. В результате работы программы сохраняется граф в формате `.png` и таблица с результатом в формате `.csv`.

Установка необходимых для консольного прложения зависимостей:
- с помощью conda: `conda install -c conda-forge pandas numpy matplotlib networkx` 
- с помощью pip: `pip install pandas numpy matplotlib networkx`

#### Запуск веб-приложения:
```bash
git clone https://github.com/Vanyush/bioinf_bootcamp_2026.git
cd bioinf_bootcamp_2026/mmnv_python

streamlit run MMNV_web.py
```
В результате выполнения команд запускается браузерное приложение. При использовании приложения необходимо загрузить FASTA-файл с набором выровненных митохондриальных последовательностей. После импорта файла и нажатия на кнопку "Открыть FASTA" автоматически стоится интерактивный граф. Результаты можно скачать как CSV-таблицу.

Установка необходимых для веб-приложения зависимостей:
- с помощью conda: `conda install -c conda-forge pandas numpy matplotlib networkx streamlit plotly` 
- с помощью pip: `pip install pandas numpy matplotlib networkx streamlit plotly`


# Использование приложения для решения задачи
## Введение
Для решения поставленной в кейсе №1 задачи было использовано описанное выше приложение. Для написания осовного алгоритма консольного и веб приложений был выбран язык программирования (ЯП) python, так как данный ЯП позволяет в короткие сроки реализовать быструю обработку итеративных операций благодаря библиотекам pandas и numpy. В качестве ЯП для разработки нативного приложения был выбран Swift по нескольким причинам:
1. Это современный кросс-платформенный компилируемый язык, обеспечивающий производительность на уровне C, при этом гарантирующий безопасность кода.
2. Под macOS Swift имеет нативный декларативный фреймворк SwiftUI, который позволяет быстро разрабатывать интуитивно-понятный GUI. Использование фреймворка Qt для C++ или egui для Rust значительно увеличило бы время разработки программы, что не позволило бы вложиться в 3 дня хакатона.
3. Отсутствие фреймворка SwiftUI на Linux и Windows может компенсироваться схожим фреймворком [SwiftCrossUI](https://github.com/moreSwift/swift-cross-ui), который позволяет переработать программу с минимальным изменением в коде.

В качестве исходных данных использовался файл [`mth_crocuta_aln_renamed.snps.fasta`](https://github.com/Vanyush/bioinf_bootcamp_2026/blob/main/completed_case_assignment/real_task/mth_crocuta_aln_renamed.snps.fasta). Данные были загружены во все приложения, результаты различались лишь визуальным представлением графа, при этом рассчитанный возраст последовательностей и расстояние между узлами графа оставались одинаковыми. 

## Результаты работы алгоритма
В результате работы алгоритмов были получены [таблица](https://github.com/Vanyush/bioinf_bootcamp_2026/blob/main/completed_case_assignment/real_task/alg1.csv), содержащая столбцы позиция во входном файле (*index*), заголовок из входного файла (*header*), данный возраст последовательности (*observed_age_bp*), рассчитанный возраст последовательности (*inferred_age_bp*), достоверность вычисления возраста (*confidence*), длина последовательности (*sequence_length*), назначенная гаплогруппа (*haplogroup*), и [граф](https://github.com/Vanyush/bioinf_bootcamp_2026/blob/main/completed_case_assignment/real_task/alg1_network.png), на котором все определенные гаплогруппы расположены в порядке возрастания возраста последовательности, синие узлы обозначают гаплогруппы с известным возрастом, оранжевые - с неизвестным. а ребра соединяют генетически близкие гаплогруппы.

В качестве референса использовался алгоритм [HapNet](https://www.researchgate.net/publication/400973467_HapNet_a_new_Python_package_for_automated_population-aware_haplotype_network_analysis_and_visualization).
